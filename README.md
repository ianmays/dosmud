# dosmud

Minimal DOS-first MUD-like prototype in ANSI C.

## Quick start

Native development build:

```sh
make build
./dosmud
```

Local strict/test checks:

```sh
make test
make test-run
```

DOS/Open Watcom path:

```sh
make prepare-dos
```
